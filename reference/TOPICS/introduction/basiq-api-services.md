Basiq provides two core API services which you can use to develop innovative financial solutions:

**Connect** provides the ability to easily acquire financial data such as account details and balances and related transactions from various financial institutions.

**Enhance** classifies all banking, credit and debit card transactions into categories based on specific merchant, merchant type and geographical location data.
