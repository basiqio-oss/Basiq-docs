## What’s included

The Enrich specification includes endpoints for:

* Enriching a transaction description with classification and metadata
* Searching merchants by merchant name, ABN, suburb, or entity type
* Retrieving merchant details by merchant ID

Use this specification when you want to improve raw transaction data with merchant, category, and payment context.
