- [Refreshing](https://basiq.readme.io/v0.9/reference#refresh-a-connection) an invalid connection (connection with invalid login credentials) is no longer possible - a Bad Request error response is returned. Invalid connection needs to be updated with valid credentials via [Connection Update](https://basiq.readme.io/v0.9/reference#update-a-connection) operation in order to perform a refresh operation.
