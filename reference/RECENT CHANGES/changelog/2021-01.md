* Added new  `alpha` stage for  [Institutions](ref:institutions) connectors, to more accurately reflect the lifecycle stage of the connector. This stage indicates that there is a new connector however it is partially complete.  You can use the features attribute for every connector to dynamically determine which data points are supported.

* Added HTTP 403 response to [Authentication](ref:authentication) (token endpoint) once a partner account disabled.

* Added HTTP 404 response to [Authentication](ref:authentication) (token endpoint) once a partner account is deleted.
