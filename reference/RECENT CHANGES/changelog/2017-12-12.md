* Previously passing an encoding value would fail, we now allow you to pass `utf-8`, this is also the default value if no encoding is specified. Any other encoding will throw an error.
* We are deprecating `transactionType` from the [Transaction](https://basiq.readme.io/v0.9/reference#transactions) resource. This is no longer valid as we have added the class / sub-class attributes which do a much better job.
