* Added support to retrieve [events](ref:events-1). This object represents an event that has occurred via another endpoint such as create user, update account or  failed job.  This feature is in `alpha` and this first release provides support for [user](ref:users) event types: `user.created`, `user.updated`, `user.deleted`.
