* Added support to [Create a connection](ref:create-a-connection)  using an authorisation token, adding new attribute `userToken`.  Use the [institutions endpoint](ref:list-all-institutions) to determine if the institution requires a user token in order to create a connection: `authorization = token`

* Added support for a  **bank-fee** [transactions](ref:retrieve-a-transaction) adding a `subClass` to indicate account behaviours on transaction accounts only for MVP - meta data as follows:
  * `overdrawn` - indicating overdrawn or overlimit fee
  * `dishonour`  - indicating direct debit dishonour fee
  * `late` - indicating a late payment fee 
  * `interest` - indicating interest charged on a transaction account
