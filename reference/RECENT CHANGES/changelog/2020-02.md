* Added [Transactions](ref:transactions) new `class` enumerator values to better classification of mortgage and loan transactions: 
  * `loan-interest` - debit transactions for interest charged for a loan
  * `loan-repayment` - credit transactions for repayments made for a loan
* Added [Institutions](ref:institutions) new attribute `forgottenPasswordUrl` - providing url to the institution forgotten password page
* Updated [Accounts](ref:accounts) attribute `accountNo` to add missing BSB and remove letters from T4 institutions
