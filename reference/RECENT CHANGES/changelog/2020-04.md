- Added [Institutions](ref:institutions) attributes `stage` and `status` providing indication of maturity and availability of web connectors
- Added filter [Institutions](ref:institutions) by `stage`
- Added `ne` (not equals) operator to filters for [Institutions](ref:institutions) 
- Updated [Affordability](ref:affordability) attribute `arrears` (true/false) calculation and also now include additional enumerator value: `null` where there is not sufficient data to make the calculation
- Updated [Affordability](ref:affordability) attribute `credit limit` for `creditLiabilities` to retrieve value from institution (where available) rather than calculating it based on [Accounts](ref:accounts) `balance` and `availableFunds` (calculation remains as fallback where credit limit unavailable
