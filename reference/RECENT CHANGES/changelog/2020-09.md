- Added the ability to pass an optional array of **accounts** in the request body when creating any of the [Affordability API](ref:affordability-api) resources.  When you create  Affordability, Income or Expenses insights only those accounts specified are listed in the response for assets, liabilities, aggregated expenses and income identification.  All transactions in non-specified accounts are ignored.
