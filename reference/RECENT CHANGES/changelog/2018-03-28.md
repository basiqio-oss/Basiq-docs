- Added `account-not-accessible-requires-user-action`[ error](https://basiq.readme.io/v2.0/reference#errors). Newest user's data is not available until end-user performs the appropriate action required by the Institution.
- Added `maintenance-error` [error](https://basiq.readme.io/v2.0/reference#errors). Data is not available due to maintenance on Institution's side.
- Added `no-production-access` [error](https://basiq.readme.io/v2.0/reference#errors). By default, registered Partners have access to Sandbox data only. In order to get access to live Institution data, please reach out to us via Intercom or email.
- Added the following [Filters](https://basiq.readme.io/v2.0/reference#filters) for [Transaction](https://basiq.readme.io/v2.0/reference#list-all-transactions) resource: `institution.id`, `transaction.status`
