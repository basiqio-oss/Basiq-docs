- Added ability to retrieve fully enriched data via [Transactions](ref:transactions)  endpoint **for partners enabled for [Enrich API](ref:enhance-api) **.  This means, no extra round trip to Enrich endpoint for each transaction.  Enriched data includes: category (4 levels, merchant and location are now returned via Transactions endpoint [Changelog](https://api.basiq.io/reference#2020-11)


- Added new granular `title` and `detail` messages for `invalid-credentials` [Error codes](ref:error-codes), these are not new error codes in order to enable backwards compatibility and error messages can be passed straight through to end users:
     -  [new] title and detail message for scenario: invalid-username-or-password
     -  [new] title and detail message for scenario: locked-account
     -  [new] title and detail message for scenario: multi-factor-authentication
     - invalid-credentials - existing generic title and detail message, fallback where no cases match from above


- Added collection to [List all affordability](ref:list-all-affordability) snapshots generated for a [Users](ref:users) 


- Extension last month's release to add further merchants to external payment providers and liabilities to [Affordability API](ref:affordability-api)  to surface relationships that are held externally to the bank accounts that have not been disclosed or linked by the user, e.g. surfacing small pay-day loans or buy now pay later services and now collections agencies.  Updated with commonly requested and viewed merchants in this space including adding collections agencies.
