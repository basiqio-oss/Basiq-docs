- [Transactions](https://basiq.readme.io/v0.9/reference#transactions) can be filtered by account ID. Filter is forwarded as a query parameter. Syntax is ?`filter[account.id]=1`
- It is possible to request [Transactions](https://basiq.readme.io/v0.9/reference#transactions) with `postDate` in a given range, i.e. request transactions before and/or after a certain date.
