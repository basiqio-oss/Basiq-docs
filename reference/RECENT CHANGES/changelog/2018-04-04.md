* In some cases when a [Connection](https://basiq.readme.io/v0.9/reference#connections) is created, updated or refreshed, we can return an error `account-not-accessible-requires-user-action`. This signals that a certain manual action from end-user is required by the Institution itself, before newest data can be acquired.
