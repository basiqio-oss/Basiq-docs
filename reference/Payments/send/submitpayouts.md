You can submit a payout instruction [Submit payouts](ref:submitpayouts), including in the instruction:
    - `requestId`: A unique ID generated by the partner application
    - `amount`: The amount of the payment you are paying out
    - `description`: The description to be included on the payment
    - `payeeUserId`: Basiq’s unique identifier given when they are created with Basiq
    - `method`: Indicating if it is a `fast`, `batch`, or `fast/batch` as detailed above 
[block:code]
{
  "codes": [
    {
      "code": "POST /payments/payouts HTTP/1.1\nAccept: application/json\nContent-Type: application/json\nAuthorization: Basic $YOUR_ACCESS_TOKEN\n\n{\n    \"payouts\": [\n        {\n            \"requestId\": \"01824ad0-73f1-0138-3700-0a58a9feac09\",\n            \"method\": \"fast\",\n            \"amount\": 512.56,\n            \"description\": \"Investment profits\",\n            \"payee\": {\n                \"payeeUserId\": \"21824ad0-73f1-0138-3700-0a58a9feac09\"\n            }\n        }\n    ]\n}\n",
      "language": "json",
      "name": "Submit Payout"
    }
  ]
}
[/block]
The response will contain the **job resource** responsible for processing this payout. **It will not return the payment itself**. You can use this job to track the progress of the payout and know when it has successfully completed. 
[block:code]
{
  "codes": [
    {
      "code": "HTTP/1.1 202 Accepted\nContent-Type: application/json\n\n{\n  \"type\": \"job\",\n  \"id\": \"33454ad0-73f1-0138-3700-0a58a9feac09\",\n  \"requestId\": \"01824ad0-73f1-0138-3700-0a58a9feac09\",\n  \"links\": {\n    \"self\": \"https://au-api.basiq.io/jobs/33454ad0-73f1-0138-3700-0a58a9feac09\"\n  }\n}",
      "language": "json"
    }
  ]
}
[/block]
Use the `job.Id` you receive to track the payouts' progress via the [Jobs](ref:getjobs) You can continue to poll this endpoint regularly to stay updated of the success/failure of your payouts.

Note: The `jobId` returned can also be used to retrieve the `payout` directly via the API
