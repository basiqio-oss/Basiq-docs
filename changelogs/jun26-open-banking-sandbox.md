We've introduced a new Open Banking Sandbox experience, allowing developers to test end-to-end Open Banking consent flows in a controlled and deterministic environment using the **Hooli OB** sandbox institution (AU00000).

## What’s new

**Open Banking Sandbox institution:** Partners can now enable Open Banking for Hooli OB (AU00000) through the Dashboard Customizer and test Open Banking consent journeys separately from standard sandbox connections.

**Mock Data Holder experience:** Partners can test complete redirect and consent experiences through a simulated Data Holder environment, including login, OTP verification, account selection, consent review, and callback handling.

**Updated testing documentation:** Added Open Banking Sandbox configuration instructions, test credentials, and onboarding information to the [Sandbox Testing documentation](https://api.basiq.io/reference/testing).

With the Open Banking Sandbox, developers can:

- Validate Open Banking integration flows end-to-end
- Test consent creation and account sharing journeys
- Test arrangement extension and re-authorization flows
- Refresh Open Banking connections and retrieve sandbox data
- Test arrangement revocation workflows
- Build and validate consent management experiences before production onboarding
- Develop against a deterministic Open Banking environment with predictable outcomes
