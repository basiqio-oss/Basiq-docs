# 🎉 December Dashboard Update (dashboard.basiq.io) 🚀

We’ve rolled out some exciting updates to improve your application creation experience!

<Tabs>
  <Tab title="What's New">
    <Cards columns={3}>
      <Card title="🏢 BCC Applications" icon="fa-building">
        Create Business Consumer (BCC) applications to help businesses manage financial data effectively.
      </Card>

      <Card title="🛡️ Trusted Adviser" icon="fa-shield-alt">
        Introduced Trusted Adviser applications for secure access to client financial data.
      </Card>

      <Card title="🎯 Default Application" icon="fa-check-circle">
        The Regular Application is now the recommended default for most use cases.
      </Card>
    </Cards>
  </Tab>

  <Tab title="Improvements">
    <Accordion title="✨ Enhanced Application Descriptions" icon="fa-info-circle">
      Each application type now includes a description:

      * **Regular Application:** For collecting data from individuals or businesses, compatible with Open Banking.
      * **BCC:** Designed for business consumers managing financial data.
      * **Trusted Adviser:** Tailored for client-facing advisers needing secure data access.
    </Accordion>

    <Accordion title="🎨 Refreshed Interface" icon="fa-paint-brush">
      A modernized "Create a new Basiq application" page with a simpler workflow:

      * **Select** and **Continue** buttons are more intuitive.
      * Easier navigation through the setup process.
    </Accordion>
  </Tab>

  <Tab title="Developer Notes">
    <Columns layout="auto">
      <Column>
        * Regular Application remains the most flexible choice.
        * New application types address specific business needs.
      </Column>

      <Column>
        * Interface updates improve usability.
        * Perfect for faster onboarding and integration.
      </Column>

      <Column>
        * Let us know your feedback for further improvements!
        * Watch this space for more enhancements.
      </Column>
    </Columns>
  </Tab>
</Tabs>
