## Basiq ConnectAuth

### Enabling access to v3.0 for partners using auth links

 

<Image width="smart" src="https://files.readme.io/c0d2b6d-EARLY-ADOPTER-MEME.jpeg" />

 \
While we work on upgrading `https://connect.basiq.io` to support v3.0 of the API, we have released an `npm` package for our partners who are itching to access CDR data. :sparkles: This UI component handles the 2FA before redirecting the user to the Basiq Consent UI. All it needs is the ID generated when creating an auth link. Check it out [here](https://www.npmjs.com/package/@basiq/connect-auth).
