# Insights release: Bank Statements :bookmark_tabs:

## New Features: :electric_plug:

* **Bank Statements Integration**: Bank Statements functionality has been added to the production environment.

### Key Points:

* **Statement Creation**: Users can now create bank statements via the Basiq API using the provided [guide](https://api.basiq.io/docs/bank-statements).
* **Statement Retrieval**: The process for retrieving bank statements has been detailed, including steps for both JSON and PDF formats.
* **Transaction Retrieval**: Users can also retrieve associated transactions for a given bank statement.
* **Quick Links Added**: Quick links have been incorporated throughout the documentation for easy navigation.

**Date of Release**: Bank Statements feature is now live in Production.
