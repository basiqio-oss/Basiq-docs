We've introduced several updates across CDR consent configuration and Basiq Connect to improve compliance, flexibility, and data holder coverage.

## What's included:

CDR Insights purpose configuration

- Consent purposes for CDR Insights are now automatically derived from the selected insight(s).
- Partners can no longer customise CDR Insights purposes, ensuring consent language remains aligned with CDR requirements.

## Retain consumer data option for TAviaPRM applications

- Added the Retain consumer data option for TAviaPRM application types in Customizer.
- Partners can now configure consent with or without consumer data retention enabled.

### Basiq Connect improvements

- Added new data holder connectors:
  - **AFG Home Loans**
  - **NRMA Home Loans**
  - **Connective Select**
  - **Tyro Banking**

If you have any questions about these updates, please reach out to Basiq Support.
