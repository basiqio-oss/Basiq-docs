We are excited to share the latest updates and improvements we've made to the API in November 2024.

## Extended Retention Field

* Introduced `extendedRetention` field in the application consent policy.

### API Updates

* `/consents` endpoints now support the `extendedRetention` field for creation and retrieval.

### Email Updates

* Updated CDR Receipt templates to reflect extendedRetention flag status.
