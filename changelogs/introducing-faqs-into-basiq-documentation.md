# October '22 :partly_sunny:

# :fireworks: What's new?

## Introducing [FAQ's](https://api.basiq.io/discuss) in BASIQ Documentation

We are introducing FAQ's in our documentations for our partners to open discussions. Please feel free to open a thread and someone will get back to you as soon as possible. 

## Introducing Creating Payment Sandbox and Production applications via BASIQ Dashboard.

Our Partners can now Create Payment Sandbox and Production applications (or edit existing ones). Whenever a Payments Production app is created, please contact us on [support@basiq.io](mailto:support@basiq.io) to the team to proceed with your application enablement. 

![934](https://files.readme.io/cb81816-image_2.png "image (2).png")

**Payments**: Head over to the [dashboard](https://dashboard.basiq.io/) to check it out

## Consent UI Updates

Partners can now pass a [connectionId](https://api.basiq.io/docs/consent-ui#update-credentials-via-consent-ui) parameter in the URL to initiate a credential update flow. This only works for non-CDR connections. 

Users will now see their previous connections pinned to the top. If a user taps on a CDR connection that they already exists, an :information_source: popup will appear

![1544](https://files.readme.io/dc27f89-image_1.png "image (1).png")

You can read more about the consent UI and other actions available [here](https://api.basiq.io/docs/consent-ui)
