## Quickstart Steps 1 & 2: Register and authenticate your app

Before you can start making requests to the Basiq API, you will need to register your application via the Basiq dashboard. You will then be able to exchange your new API key to authenticate your application and request an `access_token`.

## Quickstart Step 3: Creating a user

The first place to start with most applications is by creating a user. This is because at Basiq, a `User` acts a bucket in which we can aggregate financial data.

## Quickstart Step 5: Fetching aggregated data

Once you have created a user and connected their financial institutions you are able to make request so fetch their aggregated financial data. This step is the last piece of the puzzle when it comes to Basiq's core functionality, and you will have all the pieces of a fully integrated application.
